# Changelog

## 0.1.5
- Settings > Updates has a What's new row that shows what an available update changes, before you install it.
- Output views of Settings extensions wrap long lines instead of cutting them.
- Settings > Updates is translated into Portuguese.

## 0.1.4
- The update notification shows its whole text on one line.
- Long confirmations from Settings extensions use up to three lines instead of being cut.
- The input daemon uses about 3% of a CPU core instead of half of one.

## 0.1.3
- Settings > GameSwitcher turns GameSwitcher off and sets GUIDE, the double tap, resume, battery levels, excluded systems and history.
- GameSwitcher takes every compatible RetroArch launcher, so systems such as Mega Drive and Super Famicom work with it.
- Wi-Fi gets its address after a reboot, so update checks work without turning Wi-Fi off and on.
- The updater verifies GitHub with the firmware's CA bundle and retries a failed check after a minute.

## 0.1.2
- Stock++ with custom Settings menus, button mappings, more LED settings, boot logo and splash screen previews and loading-screen presets.
- Replacement input, OSD and LED daemons, the RetroArch in-game menu and GameSwitcher.
- Fixes for Bluetooth pairing, menu audio, Wi-Fi passwords, search, game counts and UTF-8 deletion.
- Settings > Updates checks GitHub releases, asks before installing and installs at the next boot.
- Independent versions for each component.
