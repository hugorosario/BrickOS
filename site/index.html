A FEW USEFUL ANSWERS

Before you start.

Is this a complete replacement firmware?+

No. BrickOS reimplements selected frontend and system components, running alongside the device’s stock firmware. The original kernel, drivers, services and emulator stack remain in use.

What does “experimental” mean here?+

The alternative BrickOS frontend is actively being developed. Appearance, features and device integration are evolving. Stock++ is the familiar stock-style presentation of the same reimplemented MainUI.

Are these screenshots from a real Brick?+

Yes. These are native 1024 × 768 captures from a real TrimUI Brick. Most show Stock++; the BrickOS desktop comes from an earlier development build. Game names and game imagery are obscured where present. Read the capture provenance.

Where can I report a bug or contribute?+

Use GitHub Issues for reproducible bugs and improvements. Include your device, release and component versions, steps to reproduce and useful logs. Source and build instructions are in the repository.
